## Evidence
The portfolio includes original embedded figures/evidence extracted from the supplied project reports:
- Secure Cloud File Sharing report: hybrid architecture, three-tier architecture, secure download flow, application dashboard and attacker model.
- Wansview Q3 IoT security assessment: lab topology, traffic capture, web portal and device-analysis evidence.

The evidence is presented as project artifacts; it is not simulated telemetry.

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

The project expects a resume at `public/resume.pdf`. Add the user's final resume there before publishing if a downloadable resume button is desired.
